# 配置指南

## 快速开始

### 1. 首次配置
访问 `setup.php` 页面，按照向导完成配置：

```bash
# 访问设置页面
http://yourdomain.com/setup.php
```

### 2. 配置步骤

#### 步骤1：微信支付配置
- **AppID**: 微信公众平台的AppID（wx开头的18位字符串）
- **商户号**: 微信支付商户号（10位数字）
- **API密钥**: 微信支付API密钥（32位字符串）
- **通知URL**: 支付结果通知地址

#### 步骤2：证书文件上传
将微信支付证书文件上传到指定目录：
```
1710407126_20250927_cert/
├── apiclient_cert.pem  # 证书文件
└── apiclient_key.pem   # 私钥文件
```

#### 步骤3：验证配置
系统会自动验证配置的完整性和正确性。

## 配置文件结构

### 主配置文件
`config/app.php` - 主配置文件，包含所有系统配置

### 配置模板
`config/app.template.php` - 配置模板文件，包含详细的配置说明

## 配置项说明

### 微信支付配置
```php
'wechat' => [
    'app_id'        => 'wx...',           // 微信AppID
    'mch_id'        => '1234567890',      // 商户号
    'key'           => 'your_api_key',    // API密钥
    'notify_url'    => 'https://...',     // 通知URL
    'sandbox'       => true,              // 沙箱模式
]
```

### 二维码配置
```php
'qr_code' => [
    'default_size' => 200,                // 默认尺寸
    'default_logo' => './favicon.ico',    // 默认Logo
    'style' => [...],                     // 样式配置
    'apis' => [...],                      // API配置
]
```

### 安全配置
```php
'security' => [
    'admin_password' => 'strong_password', // 管理密码
    'force_https'    => false,             // 强制HTTPS
    'allowed_ips'    => [...],            // 允许的IP
]
```

## 常见问题

### Q: 如何获取微信支付配置？
A:
1. **AppID**: 微信公众平台 → 开发 → 基本配置
2. **商户号**: 微信支付商户平台 → 账户中心 → 商户信息
3. **API密钥**: 微信支付商户平台 → 账户中心 → API安全
4. **证书文件**: 微信支付商户平台 → 账户中心 → API安全 → 下载证书

### Q: 沙箱模式和正式模式的区别？
A:
- **沙箱模式**: 用于测试，不需要真实支付
- **正式模式**: 用于生产，需要真实支付

### Q: 配置保存失败怎么办？
A:
1. 检查文件权限
2. 检查配置格式
3. 查看错误日志

## 安全建议

1. **修改默认密码**: 更改 `security.admin_password`
2. **启用HTTPS**: 生产环境设置 `security.force_https = true`
3. **限制IP访问**: 配置 `security.allowed_ips`
4. **定期备份**: 备份配置文件和证书文件
