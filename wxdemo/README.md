# 微信支付二维码生成系统

一个基于PHP的微信支付集成系统，支持二维码生成、支付处理和管理功能。

## 🚀 主要功能

### 💳 微信支付集成
- **统一支付接口** - 支持微信支付API v2
- **二维码生成** - 自动生成支付二维码
- **支付回调** - 处理微信支付结果通知
- **订单管理** - 创建和查询支付订单

### 🔧 配置管理
- **可视化配置** - 通过Web界面完成所有配置
- **配置验证** - 自动检查配置完整性和正确性
- **实时同步** - 配置修改后立即同步到文件
- **默认配置** - 提供完整的默认配置模板

### 📁 证书管理
- **文件上传** - 支持直接上传证书文件
- **文本提交** - 支持复制粘贴证书内容
- **自动创建** - 自动创建证书目录
- **状态监控** - 实时显示证书文件状态

### 🎨 二维码生成
- **多API支持** - 集成多个在线二维码生成服务
- **样式定制** - 支持Logo、边框、阴影等样式
- **备用策略** - 自动切换备用API
- **本地缓存** - 支持本地二维码生成

## ✨ 核心特点

### 🛡️ 安全可靠
- **沙箱模式** - 支持测试和生产环境切换
- **HTTPS支持** - 强制HTTPS安全传输
- **IP限制** - 支持管理功能IP访问限制
- **错误处理** - 完善的异常处理和日志记录

### 🎯 最小代码
- **最少依赖** - 仅依赖EasyWeChat和Monolog
- **简洁架构** - 单文件入口，模块化设计
- **自动加载** - 智能类加载机制
- **配置驱动** - 所有功能通过配置控制

### 📊 管理功能
- **实时监控** - 系统状态实时显示
- **日志查看** - 完整的操作日志记录
- **配置管理** - 可视化配置界面
- **测试工具** - 内置功能测试工具

## 🏗️ 技术架构

### 核心组件
- **ConfigManager** - 配置管理器，支持嵌套配置
- **WeChatPay** - 微信支付处理类
- **QRCodeGenerator** - 二维码生成器
- **CertManager** - 证书文件管理器
- **Logger** - 日志记录器

### 技术栈
- **PHP 7.4+** - 现代PHP特性支持
- **EasyWeChat** - 微信SDK集成
- **Monolog** - 专业日志处理
- **HTML5/CSS3** - 现代化界面
- **JavaScript ES6** - 前端交互

## 📦 快速开始

### 1. 环境要求
- PHP 7.4 或更高版本
- Composer 包管理器
- Web服务器（Apache/Nginx）

### 2. 安装部署
```bash
# 克隆项目
git clone <repository-url>
cd wxdemo

# 安装依赖
composer install

# 配置Web服务器指向项目根目录
```

### 3. 配置系统
1. 访问 `setup.php` 页面
2. 填写微信支付配置信息
3. 上传证书文件或粘贴证书内容
4. 保存配置并验证

### 4. 开始使用
- **支付页面**: `index.php`
- **管理面板**: `index.php?action=admin`
- **系统测试**: `index.php?action=test`

## 🔧 配置说明

### 微信支付配置
```php
'wechat' => [
    'app_id'        => 'wx...',           // 微信AppID
    'mch_id'        => '1234567890',      // 商户号
    'key'           => 'your_api_key',    // API密钥
    'v2_secret_key' => 'your_api_key',    // V2密钥（与key一致）
    'notify_url'    => 'https://...',     // 通知URL
    'sandbox'       => true,              // 沙箱模式
]
```

### 二维码配置
```php
'qr_code' => [
    'default_size' => 200,                // 默认尺寸
    'default_logo' => './favicon.ico',    // 默认Logo
    'style' => [...],                     // 样式配置
    'apis' => [...],                      // API配置
]
```
